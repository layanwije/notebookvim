# Security Policy

## Supported versions

NotebookVim is currently maintained on its latest released version. Security
fixes are applied to the latest release and to the `main` branch. Older versions
may not receive security updates.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue, discussion,
or pull request.

Use GitHub's private vulnerability reporting feature instead:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include, when possible:

- A description of the vulnerability and its potential impact.
- The affected version or commit.
- Steps or a minimal example that reproduces the issue.
- Any suggested mitigation or fix.

You should receive an acknowledgement within seven days. Please allow a
reasonable amount of time for investigation and remediation before publicly
disclosing the issue.

If private vulnerability reporting is unavailable, contact the maintainer
through their GitHub profile without including sensitive details in a public
message.

## Scope

Security reports should concern NotebookVim itself. Vulnerabilities in a
third-party dependency should also be reported to that dependency's maintainers.
If the dependency issue creates a direct risk for NotebookVim users, you may
additionally report it here.
